# 🏍 Smart Helmet using YOLO Algorithm  

## 📌 Project Description  
This project is developed to *improve the safety of motorcyclists* using a combination of sensors, microcontrollers, and the YOLO (You Only Look Once) deep learning algorithm.  

- 🚨 Alerts the rider when the speed limit is exceeded.  
- ⛑ Bike engine starts only if the rider is wearing a helmet.  
- 🍺 Alcohol detection using MQ-3 sensor — if alcohol is detected, the engine will not start.  
- 📡 Wireless communication between the helmet unit and the bike unit using RF modules.  
- 🤖 YOLO algorithm is used to detect helmet usage in real-time.  

---

## ⚙ Features  
- Helmet Detection (YOLO Algorithm)  
- Alcohol Detection (MQ-3 Sensor)  
- Speed Monitoring (BLDC Fan as speed sensor)  
- Engine Control using AT89S52 Microcontroller  
- Wireless Communication (315 MHz RF Module)  
- Real-time YOLO Visualization
